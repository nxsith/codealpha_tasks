# Dataset: Pima Indians Diabetes

The `diabetes.csv` file contains the standard Pima Indians Diabetes dataset used in many introductory machine-learning examples. It has 768 rows, eight input features, and one `Outcome` label.

The raw file has no header row. The training script assigns these columns:

1. `Pregnancies`
2. `Glucose`
3. `BloodPressure`
4. `SkinThickness`
5. `Insulin`
6. `BMI`
7. `DiabetesPedigreeFunction`
8. `Age`
9. `Outcome`

`Outcome` is 0 for a negative result and 1 for a positive result in this historical dataset. This data must only be used for educational purposes; it is not a diagnostic dataset for real clinical use.
