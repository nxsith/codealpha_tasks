# CodeAlpha Machine Learning Internship Tasks

This repository contains three completed machine-learning internship tasks.

| Task | Project | Summary |
|---|---|---|
| Task 1 | [Credit Scoring Model](./CreditScoringModel) | Classifies historical credit risk using Logistic Regression and Random Forest. |
| Task 3 | [Handwritten Character Recognition](./HandWrittenCharacterRecognition) | Recognises MNIST handwritten digits using a Convolutional Neural Network. |
| Task 4 | [Disease Prediction from Medical Data](./CodeAlpha_DiseasePrediction) | Classifies historical diabetes-dataset outcomes using three machine-learning models. |

Each project folder has its own README with dataset details, setup instructions, results, visual outputs, and limitations.

All projects are educational demonstrations only. They are not for real lending, medical, or clinical decisions.
